# 릴스 편집 도구 (template-reels-edit)

촬영한 세로 릴스 원본(말하는 영상)을 **CapCut 프로젝트와 업로드용 mp4까지** 편집해 주는 Claude Code 도구입니다.
반복 테이크 중 가장 깔끔한 것을 골라 점프컷으로 자르고, 자막·강조·확대·효과음·화면 자료(모션그래픽)를 넣은 뒤 CapCut에 한 번에 조립합니다.

**이 저장소는 템플릿입니다.** 만든 사람의 편집 스타일(편집 기준표·자막 모양·브랜드 색)은 들어 있지 않습니다. 받은 분이 고른 기준 릴스 3편과, 직접 편집해 둔 CapCut 프로젝트로 **내 편집 스타일을 새로 학습**한 뒤 씁니다.

## 설치 — 붙여 넣기 두 번

**① VS Code의 Claude 패널(아무 폴더나 괜찮아요)에 붙여 넣기**

```
https://github.com/gfmmmm/template-reels-edit 를 홈 폴더 아래 reels-edit 폴더로 내려받고, 다음에 제가 할 일을 알려 주세요. (README의 "Claude Code에게" 절대로 해 주세요)
```

**② 안내대로 VS Code에서 `reels-edit` 폴더를 연 다음, 새 대화에서**

```
구축 가이드대로 진행해줘
```

그다음은 Claude Code가 [SETUP.md](SETUP.md)를 읽고 **설치 → 내 스타일 학습 → 편집 가능** 순서로 이끌어 줍니다. 컴퓨터 쪽 일은 Claude가 하고, 본인은 질문에 답하고 설치 창에서 "허용"만 누르면 됩니다.

학습 때 묻는 것 — 미리 준비해 두면 빨라요.
- 내 편집 기준이 될 릴스 링크 3개 (내 릴스 중 잘 된 것, 또는 닮고 싶은 계정 것)
- 내가 직접 편집해서 마음에 들었던 CapCut 프로젝트 이름 (없어도 됩니다)
- 평소 쓰는 자막 글꼴

## 필요한 것

| 항목 | 내용 |
|---|---|
| 컴퓨터 | 맥(애플 칩) 권장. 인텔 맥·윈도우는 받아쓰기·얼굴 인식이 다른 도구로 돌아요. **윈도우는 아직 실제로 시험하지 않았어요** — CapCut 내보내기·화면 검수는 직접 합니다 |
| CapCut | 데스크톱 **9.x 버전** (10 이상은 자동 편집이 막혀요) |
| Claude Code | VS Code(또는 VS Code 계열) + Claude Code 확장, 로그인(유료 플랜) |
| 키 | Gemini API 키 — https://aistudio.google.com/apikey 에서 무료 발급 (레퍼런스 분석·효과음 이름 붙이기) |
| 선택 | OpenAI 키(AI 그림이 필요할 때), Fish Audio(내 목소리 나레이션) |
| 디스크 | 여유 10GB 이상 (받아쓰기 모델·Remotion·결과 영상) |

키는 채팅에 붙이지 않고 Claude가 알려 주는 대로 터미널에 직접 넣습니다.

## 쓰는 법

```
/릴스편집 이 영상 편집해줘
```
영상 파일을 대화창에 끌어다 놓고 보냅니다. 여러 파일이면 대본에 파일 이름을 적어 주세요.

1. 질문에 답합니다 — 대본 · 원하는 느낌 · 자료 화면 ("추천대로"도 돼요)
2. 컷편집 → 효과 → CapCut 프로젝트 → 확인용 영상과 풀스크립트
3. CapCut에서 열어 재생·저장·내보내기 → 내보낸 파일 위치를 알려 주면 업로드용 파일이 나옵니다

이어서 할 때: "릴스 편집 이어서", "편집 어디까지 했지", "풀스크립트 줘"

## 쓰면서 키우기

- 결과가 아쉬우면 그대로 말합니다 — 색·글꼴·자막 모양·규칙이 내 `편집메뉴얼.md`·`presets/`·`brand.ts`에 쌓여 다음 편집부터 반영됩니다
- "편집메뉴얼 다시 만들어줘" — 기준 릴스를 바꾸고 싶을 때
- "정답지랑 비교해" — 내가 직접 편집한 것과 도구 결과를 나란히 놓고 고칠 점을 찾습니다

## 새 버전 받기

```
업데이트 받아줘
```
도구 부분만 새 판으로 바뀌고, 내가 학습시킨 편집 기준표·자막 모양·효과음 등록분은 그대로 남습니다. 옛 판은 `_보관/`에 남아요.

## 들어 있지 않은 것

- **만든 사람의 편집 스타일** — 학습 단계에서 내 것으로 새로 만듭니다
- **효과음 소리 파일** — CapCut 라이브러리 소리라 다시 배포할 수 없습니다. 대신 `sfx/추천효과음.md`에 소리 이름과 "원래 CapCut 이름"이 있어서, 내 CapCut 효과음 검색창에서 같은 이름으로 골라 넣으면 됩니다(설치 때 Claude가 안내)
- **CapCut 글꼴 파일** — 내 CapCut에 있는 글꼴을 씁니다. 들어 있는 글꼴은 도현체(SIL Open Font License) 하나입니다

## 폴더 구조

```
reels-edit/
├── README.md · SETUP.md       설명서 · 구축 가이드(Claude가 읽고 안내)
├── update.sh                  새 버전 받기
└── .claude/
    ├── CLAUDE.md              이 폴더에서 Claude가 지킬 규칙
    ├── settings.json          허가창을 줄이는 허용 목록
    ├── agents/                검수 에이전트 2개(릴스검수·릴스대조)
    └── skills/릴스편집/       도구 본체 — 단계 파일 0~5 · scripts/ · remotion/(모션그래픽 소스) · sfx/ · templates/
```
영상·결과물은 이 폴더 밖(맥 `~/Movies/릴스편집`, 윈도우 `~/Videos/릴스편집`)에, Remotion은 `~/Projects/reels-edit-remotion`에 따로 만들어집니다.

## Claude Code에게 — 사용자가 이 링크를 주며 내려받아 달라고 했다면

1. 받을 곳: 사용자가 말한 곳, 없으면 홈 폴더 아래 `reels-edit`. 이미 있으면 덮지 말고 먼저 묻는다(이미 쓰던 폴더면 "업데이트 받아줘"가 맞다).
2. 내려받기: `curl -L -o /tmp/reels-edit.zip https://github.com/gfmmmm/template-reels-edit/archive/refs/heads/main.zip`, 압축을 풀고(`unzip`이 없으면 `python3 -m zipfile -e`) 안의 `template-reels-edit-main` 폴더를 받을 곳으로 옮긴다. 윈도우는 Git Bash 기준으로 같은 명령을 쓴다.
3. 사용자에게 딱 두 줄로 안내한다 — "폴더가 생겼어요. VS Code 메뉴 파일 → 폴더 열기로 그 폴더를 연 다음, Claude 패널에서 새 대화를 열고 '구축 가이드대로 진행해줘'라고 말해 주세요." (이 폴더의 규칙과 스킬은 그 폴더를 열어야 읽힌다. 터미널을 쓰는 사람이면 그 폴더에서 `claude`를 실행해도 같다.)
4. 그 폴더에서 열린 Claude Code는 `SETUP.md`를 읽고 진행한다.

## 버전

`VERSION` 파일 참고. 윈도우 경로는 미검증입니다 — 막히는 곳이 있으면 Claude에게 그대로 말해 주세요.
