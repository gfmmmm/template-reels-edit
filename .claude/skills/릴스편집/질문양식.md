# 질문 묶음 양식 (/릴스대본기획과 같은 꼴)

단계 시작 전에 필요한 결정을 두 번에 나눠 묻는다. 초보자가 바로 답할 수 있는 일상어로. 전문 용어는 괄호로 풀어 쓴다.

**1) 시작 질문 — 채팅 본문에.** 앞머리 없이 아래 꼴만.

```
## Q1. 질문 (한 문장)

보조 설명 한두 줄 (없어도 됨)

---

## Q2. ...
```

**2) 확인 질문 — AskUserQuestion 팝업으로.** 시작 질문 답을 읽고 AI가 추측해야 하는 것만. 없으면 띄우지 않는다. 질문 최대 4개·선택지 2~4개·머리표 12자 이내·전부 한국어.

- "추천:" 줄·"(추천)" 표시는 달지 않는다. 질문 뒤에 쓸데없는 설명·예시를 덧붙이지 않는다.
- AI가 판단할 수 있는 것(편집 느낌, 쓸 도구)은 묻지 않는다.
- 답을 받은 뒤에는 그 단계를 끝까지 진행한다(예외: 3단계 카드 디자인 승인).
