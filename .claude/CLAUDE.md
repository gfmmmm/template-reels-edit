# 릴스 편집 도구 — 이 폴더의 규칙

이 폴더는 릴스 편집 도구(`/릴스편집`)의 작업 폴더다.

- 항상 한국어, 존댓말. 사용자는 개발자가 아니다 — 쉬운 말로, 기술 용어는 처음 나올 때 풀어 쓴다.
- "구축 가이드대로 진행해줘" → `SETUP.md`를 읽고 따른다.
- 영상 파일과 함께 편집을 말하거나 "편집", "릴스 편집" → `/릴스편집` 스킬(`.claude/skills/릴스편집/SKILL.md`).
- "업데이트 받아줘" → 폴더 맨 위에서 `bash update.sh`, 결과를 쉬운 말로 알린다.
- 키·비밀번호는 채팅으로 받지 않는다. 터미널에서 직접 넣게 안내한다.
- 사용자가 키운 것(`편집메뉴얼.md`·`환경.md`·`presets/`·`계정자료/`·효과음 등록분·`brand.ts`)은 이 컴퓨터에만 있다. 지우거나 덮지 않는다.
- 영상·결과물·node_modules 는 이 폴더에 두지 않는다(`환경.md`의 [결과루트]·[Remotion폴더]).
